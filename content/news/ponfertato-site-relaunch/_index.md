Личный сайт-визитка **ponfertato.potatoenergy.ru** вновь открыт для посетителей.

### Разделы

- 👤 **О себе** - краткий профиль, навыки, подход к работе
- 🗂 **Проекты** - избранные репозитории с описанием архитектуры и решений
- 🔗 **Контакты** - ссылки на все активные каналы связи
- 🌓 **Двуязычность** - переключение между русской и английской версиями

### Технологии

Сайт собран на **Hugo + Blowfish**:

- ⚡ Статическая генерация - мгновенная загрузка
- 🎨 Тёмная тема по умолчанию, адаптивный дизайн
- 🔐 Отсутствие телеметрии, открытый исходный код
- 🐙 Исходники: [Codeberg](https://codeberg.org/ponfertato/ponfertato.site)

### Назначение

Сайт используется как единая точка для публикации ссылок на профиль и проекты.

Если интересуют:

- Примеры конфигураций NixOS / Docker Compose
- Устройство игровых серверов проекта
- Принципы работы "Potato Energy"

- сайт доступен по адресу: [ponfertato.potatoenergy.ru](https://ponfertato.potatoenergy.ru)
