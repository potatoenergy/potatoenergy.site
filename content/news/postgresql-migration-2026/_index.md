Завершена плановая миграция баз данных проекта Potato Energy. Переход выполнен без потери данных и с минимальным временем простоя.

### Что изменилось

| Сервис        | Было            | Стало               | Причина                                                                            |
| ------------- | --------------- | ------------------- | ---------------------------------------------------------------------------------- |
| **Authelia**  | PostgreSQL 15.x | **PostgreSQL 18.x** | Требуется для новых функций аутентификации и повышения безопасности                |
| **Mastodon**  | PostgreSQL 15.x | **PostgreSQL 18.x** | Поддержка современных версий ActivityPub и улучшенная производительность федерации |
| **Nextcloud** | PostgreSQL 15.x | **PostgreSQL 17.x** | Стабильная ветка с долгосрочной поддержкой, совместимость с текущими плагинами     |

> 💡 PostgreSQL 18 вышел 25 сентября 2025 года. Он приносит улучшенную производительность I/O, расширенные возможности партиционирования и обновлённый планировщик запросов.

### Как проходила миграция

1. **Логический бэкап** — `pg_dumpall` для всех баз данных
2. **Физический архив томов** — страховочная копия сырых данных
3. **Развёртывание новых контейнеров** — с обновлёнными образами
4. **Восстановление данных** — `psql < pg_dumpall.sql`
5. **Верификация** — проверка версий, путей и целостности таблиц

Процесс описан в технической статье: [PostgreSQL в Docker: Миграция между версиями без потери данных](/blog/infrastructure/docker/postgres-upgrade/)
