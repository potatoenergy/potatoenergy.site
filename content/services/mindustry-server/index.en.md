### Mindustry: Game Server [🏭](https://mindustrygame.github.io/)

**Strategic sandbox** about the construction of production facilities and tactical battles.

**What's on the server:**

- ⚙️ Production chains: ore → processing → logistics → army
- 🔫 PvE campaigns against waves of enemies and PvP battles for up to 16 players
- 🗺️ Map rotation: sandbox, survival, sector capture
- 🗳️ Map voting, pauses and restarts
- 💬 Chat synchronization with Discord

**How to connect:**

1. Launch the current version of Mindustry
2. Open "Multiplayer" → "Add Server"
3. Enter the address: `connect.potatoenergy.ru:6567`
4. Connect

**Rules:**
No cheating, respect timings, coordinate in the chat. Details are on the server.
