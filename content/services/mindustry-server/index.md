### Песочница реального времени [🏭](https://mindustrygame.github.io/)

**Назначение**  
Стратегическая платформа для:
- Строительства автоматизированных производственных цепочек
- Защиты баз от волн противников
- Мультиплеерных PvP-сражений
- Создания кастомных сценариев

**Техническая реализация**  
- Версия игры: **146**  
- Образ: Официальный Docker-образ с GraalVM  
- Портs: 6567 (TCP/UDP)  
- Хранение: Локальные конфиги и карты  
- Производительность: Оптимизация под ARM-архитектуры  

**Безопасность и доступ**  
- Аутентификация: IP-верификация  
- Модерация: Встроенные инструменты админа  
- Резервирование: Ручные снепшоты мира  
- Сеть: Изолированный Docker-сегмент  

**Особенности**  
- Поддержка 16 игроков одновременно  
- Система голосования за смену карты  
- Синхронизация с игровым каналом Discord  
- Оповещения о волнах атак в Discord  
- Бот `mindustry#6994` для двустороннего общения

---

### Пример конфигурации сервера
```properties
name=Potato Energy Battleground
map=fortress
mode=survival
difficulty=3
maxPlayers=16
```
*Настройки сохраняются в примонтированном volume*

### Система команд
```bash
# Старт сервера с кастомной картой
host --map nuclear-complex --mode attack
# Загрузка пользовательского мода
mod add "https://github.com/author/modname"
```
