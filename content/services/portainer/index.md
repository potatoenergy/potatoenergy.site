### Portainer: Визуальный контроль инфраструктуры [🎛️](https://www.portainer.io/)

**Панель управления** всеми сервисами в одном месте.

**Что делает:**

- 🐳 Управление контейнерами, образами, сетями и томами Docker через веб-интерфейс
- 📦 Развёртывание стеков из Docker Compose в один клик
- 🔄 Авто-деплой из Git-репозитория: пуш в репо → обновление сервиса
- 💻 Веб-терминал и логи контейнеров - доступ к отладке без SSH
- 📊 Мониторинг ресурсов: CPU, RAM, дисковое пространство в реальном времени

**Как пользоваться:**

1. Откройте `portainer.potatoenergy.ru` (доступ только для группы `admin`)
2. Войдите под учётной записью Potato Energy (через Authelia)
3. Выбирайте сервис → управляйте, перезапускайте, смотрите логи

**Для администраторов:**
Роли и права доступа, аудит действий, шаблоны развёртывания, интеграция с registries.

**Доступ:** `portainer.potatoenergy.ru` • по учётным данным Potato Energy (только по правам группы `admin`)
