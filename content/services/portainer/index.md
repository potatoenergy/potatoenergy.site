### Portainer: Панель управления контейнерами [🎛️](https://www.portainer.io/)

**Панель управления** всеми сервисами в одном интерфейсе.

**Функции:**

- 🐳 Управление контейнерами, образами, сетями и томами Docker через веб-интерфейс
- 📦 Развёртывание стеков из Docker Compose в один клик
- 🔄 Автодеплой из Git-репозитория: пуш в репозиторий → обновление сервиса
- 💻 Веб-терминал и логи контейнеров - доступ к отладке без SSH
- 📊 Мониторинг ресурсов: CPU, RAM, дисковое пространство в реальном времени

**Использование:**

1. Открыть `portainer.potatoenergy.ru` (доступ только для группы `admin`)
2. Войти под учётной записью Potato Energy (через Authelia)
3. Выбрать сервис → управлять, перезапускать, просматривать логи

**Для администраторов:**
Роли и права доступа, аудит действий, шаблоны развёртывания, интеграция с registries.

**Доступ:**
`portainer.potatoenergy.ru` • по учётным данным Potato Energy (только по правам группы `admin`)
