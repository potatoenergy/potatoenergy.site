### Социальная сеть нового типа [🌐](https://joinmastodon.org/)

**Назначение**  
Открытая платформа для:
- Публикации постов и медиа
- Взаимодействия с федеративными экземплярами
- Создания сообществ (инстансов)
- Модерации контента

**Техническая реализация**  
- Версия: **v4.4.0**
- База данных: PostgreSQL 15
- Очереди задач: Redis 8.0.3 + Sidekiq
- Архитектура: Микросервисная (5 компонентов)
- Локализация: Полная поддержка русского

**Безопасность и доступ**  
- Аутентификация: OIDC через Authelia
- Шифрование: E2E для личных сообщений
- Модерация: Инструменты для групп `admin` и `moderator`
- Аудит: Хранение логов 12 месяцев

**Особенности**  
- Поддержка ActivityPub
- Кастомные эмодзи и темы
- Расширенные настройки приватности
- Интеграция с Prometheus для мониторинга

---

### Пример федерации
```yaml
services:
  web: # Обработка HTTP-запросов
  streaming: # Реалтайм обновления
  sidekiq: # Фоновые задачи
  postgres: # Хранилище данных
  redis: # Кэширование сессий
```
*Обрабатывает 500+ операций в секунду*

# Почему это важно?
1. **Контроль данных** без централизованных платформ
2. **Совместимость** с Fediverse (PeerTube, Pixelfed)
3. **Гибкая модерация** контента
4. **Прозрачность** алгоритмов ленты
