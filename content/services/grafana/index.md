### Мониторинговая панель управления [📈](https://grafana.com/)

**Назначение**  
Единое пространство для:
- Визуализации метрик Prometheus
- Анализа логов инфраструктуры
- Создания кастомных дашбордов
- Совместной работы с данными

**Техническая реализация**  
- Версия: **OSS 11.6.0**
- Источники данных: 15+ интеграций
- Хранение: Локальный volume с бэкапами
- Авторизация: OAuth2 через Authelia
- Роли: Динамическое назначение через группы

**Безопасность и доступ**  
- Анонимный доступ: Только просмотр (Viewer)
- Редактирование: Группа `dev` (Editor)
- Администрирование: Группа `admin`
- Сессии: JWT с 12-часовым TTL

**Особенности**  
- 50+ предустановленных дашбордов
- SQL-like запросы к метрикам
- Экспорт отчетов в PDF
- Система аннотаций событий

---

### Интеграция с экосистемой
```yaml
auth:
  oauth:
    role_mapping: |
      contains(groups[*], 'admin') ? 'Admin' : 
      contains(groups[*], 'dev') ? 'Editor' : 
      'Viewer'
```
*Автоматическая синхронизация прав с Authelia*

---

# Почему это важно?
1. **Единый интерфейс** для всех метрик
2. **Гибкие алерты** с привязкой к дашбордам
3. **Кроссплатформенный анализ** (Prometheus/Loki/MySQL)
4. **Совместная работа** через shared snapshots

Пример использования: [Доступность сервисов](https://potatoenergy.ru/grafana/d/cadvisor-exporter/container-monitoring). Для создания персональных дашбордов обратитесь к участникам группы `dev`.
