### AI-платформа нового поколения [🤖](https://github.com/open-webui/open-webui)

**Назначение**  
Персонализированный ИИ-ассистент с:
- Генерацией текста на русском языке
- Поиском информации в реальном времени
- Анализом документов и медиа-контента
- Интеграцией с внешними API

**Техническая реализация**  
- Версия: **v0.6.15** 
- Ядро: RAG-архитектура с веб-поиском
- Кэширование: Redis 8.0.3
- Локализация: Полная поддержка русского
- Мониторинг: OpenTelemetry + Prometheus

**Безопасность и доступ**  
- Аутентификация: OAuth2 через Authelia
- Роли: 
  - Админы (группа `admin`) — полный доступ
  - Пользователи — базовые функции
- Данные: Шифрование хранилища AES-256

**Особенности**  
- Поиск через Google Programmable Search
- Обработка YouTube-видео на родном языке
- Экспорт диалогов в Markdown/PDF
- Система веб-хуков для интеграций

```python

    return await google_pse_search(
        engine_id="a6fd1036793ad45e8",
        api_key="...",
        query=query,
        lang="ru"
    )
```
