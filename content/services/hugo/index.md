### Генератор статических сайтов [📖](https://gohugo.io/)

**Назначение**  
Быстрая публикация документации и блогов с:
- Мгновенным обновлением контента
- Поддержкой Markdown
- Автоматическим построением навигации
- Предпросмотром черновиков

**Техническая реализация**  
- Версия: **0.148.0** 
- Сборка: Режим разработки с живой перезагрузкой
- Темы: Кастомные шаблоны
- Интеграция: Автоматический деплой через Git

**Безопасность и доступ**  
- Редактирование: Только через CI/CD
- Публикация: Автоматическая после мержа в main
- История изменений: Git-лог за весь период
- Резервирование: Ежечасные снепшоты

**Особенности**  
- Поддержка shortcodes
- SEO-оптимизация из коробки
- Мультиязычность
- Интеграция с OpenGraph

### Система комментариев [💬](https://remark42.com/)

**Назначение**  
Децентрализованная платформа для:
- Обсуждения материалов
- Анонимного комментирования
- Модерации контента
- Сбора фидбэка

**Техническая реализация**  
- Версия: **v1.14.0**
- Хранение: Локальный volume
- Модерация: Веб-интерфейс для админов
- Уведомления: Discord + Telegram

**Безопасность и доступ**  
- Аутентификация: Telegram или анонимно
- Модерация: Группа `admin`
- Данные: GDPR-совместимое хранение
- Резервирование: Ежедневные бэкапы

**Особенности**  
- Голосования и реакции
- Поддержка markdown в комментариях
- Автомодерация через AI
- Экспорт данных в JSON

### Пример интеграции
```html
<script>
  var remark_config = {
    host: 'https://potatoenergy.ru/remark42',
    site_id: 'potatoenergy',
    components: ['embed']
  };
</script>
```
*Добавляется в шаблон Hugo автоматически*
