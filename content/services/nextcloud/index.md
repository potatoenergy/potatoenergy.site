### Облачная платформа нового уровня [☁️](https://nextcloud.com/)

**Назначение**  
Безопасное пространство для:
- Хранения и синхронизации файлов
- Совместной работы над документами
- Видеоконференций через Spreed
- Управления задачами и календарями

**Техническая реализация**  
- Версия: **31.0.6**
- База данных: PostgreSQL 15
- Кэширование: Redis 8.0.3
- Архитектура: Микросервисная (6 компонентов)
- Мониторинг: Экспорт метрик в Prometheus

**Безопасность и доступ**  
- Аутентификация: OIDC через Authelia
- Шифрование: Серверное AES-256
- Роли: 
  - Группа `pro` — расширенное хранилище
  - Все пользователи — базовый доступ
- Аудит: Журналирование всех операций

**Особенности**  
- Автоматическая оптимизация изображений
- Интеграция с OnlyOffice
- Поддержка WebDAV/CalDAV
- Система квот для пользователей

### Пример архитектуры
```yaml
services:
  postgres: # Хранилище метаданных
  redis: # Кэш сессий
  nextcloud: # Ядро платформы
  nginx: # Обработка запросов
  cron: # Фоновые задачи
  exporter: # Мониторинг
```
*Обрабатывает 1000+ запросов в минуту*
