## 🥔 About the Project

Potato Energy is a **self-hosted home project**, provided «as is». This is not a commercial service, but a personal infrastructure for myself and a limited circle of users.

---

## 📋 What Data Is Collected

| Data Type         | Where It's Collected                                   | Purpose                             |
| ----------------- | ------------------------------------------------------ | ----------------------------------- |
| Login / Username  | All internal services with authentication              | User identification                 |
| Password Hash     | Authelia, internal services with authentication        | Secure login                        |
| Email             | Authelia, Nextcloud, Mastodon, Open-WebUI, Grafana     | Notifications, account recovery     |
| IP Address        | Traefik/Nginx logs (reverse proxies)                   | Security, attack prevention         |
| Files & Documents | Nextcloud, Mastodon, Open-WebUI, Drawpile              | Storage at your request             |
| Chat Messages     | Nextcloud, Mastodon, Open-WebUI, game servers, Discord | Communication between users         |
| Game Progress     | Minecraft, Terraria, Mindustry                         | Saving world state and achievements |

---

## 🗄️ Where Data Is Stored

- **Primary storage:** locally on the Potato Energy server (Russia)
- **Backups:** on the same server, encrypted when necessary
- **Third-party services:** only if you use integrations yourself (GitHub, Discord, Steam, etc.) - their policies apply separately

---

## 🔐 How Data Is Protected

- All connections use TLS (Let's Encrypt)
- Passwords are stored only in hashed form
- Admin panel access is protected via Authelia with 2FA support
- Access logs are automatically deleted after 90 days
- No third-party trackers, ads, or analytics

---

## 📤 When Data Is Shared

Data is **not sold or shared** for commercial purposes.

Sharing may occur only:

- At your explicit request (account or file export)
- Upon lawful request from authorized Russian authorities
- In federated services (Nextcloud/Mastodon) - public posts are visible to other instances via the ActivityPub standard

---
